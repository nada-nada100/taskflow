# Self Reflection - TaskFlow Project

---

## The Hardest Part

The hardest part of this project was **deploying the application**.

I struggled to connect the frontend to the backend because the API URL needed to change between local development and production. When I changed the URL for Render, it broke Live Server. When I changed it back for Live Server, it broke Render.

I also had issues with screenshots not showing in the README because the file paths were wrong.

---

## What I Am Most Proud Of

I am most proud of learning **full-stack development**.

Before this project, I knew nothing about Node.js, Express, or databases. Now I have built a complete working app with:

- User authentication
- Password hashing
- CRUD operations
- Filtering and search
- Charts and statistics
- Dark mode
- Deployment to the cloud

---

## What I Would Do Differently

If I did this project again, I would:

- **Plan deployment earlier** instead of leaving it to the end
- **Test the production environment sooner** to catch issues early
- **Organize files better** from the start

---

## What I Learned

- How to build a REST API with Express
- How to use SQLite for data storage
- How JWT authentication works
- How to hash passwords with bcrypt
- How to deploy a full-stack app to Render
- How to debug issues in both frontend and backend
- How to work with Git and GitHub

---

## Final Thoughts

This project taught me that **deployment and debugging** are just as important as writing code. I also learned that small configuration mistakes (like a wrong file path) can cause big problems.

I am proud of what I built and excited to continue learning.
